## 0. 现状与本文职责

取证结论（已在真实浏览器核实，非推测）：

- **色彩 token 已存在且合规**：`tokens.css:15-90`（浅色）与 `tokens.css:93-128`（暗色，选择器 `html[data-theme="dark"], html.dark`）两套完整。**本文第 2 节实测两套色板均已达 WCAG AA**。
- **暗色从未接线**：全库 `grep data-theme` 0 命中；`prefers-color-scheme` 在 4 个 CSS 中命中 0 次（`audit.json`）；11/11 页 `themeLinked=false`。
- **唯一"暗色"硬接线是错的**：`settings.html:13` 写死 `body class="theme-dark"`，而 token 选择器目标是 `html`。`settings.html:135-142` 的 toggle 切换的是 `body.theme-dark` → 永不匹配 `html.dark` → **无效**。
- **四套 CSS 并存、加载不一致**（`UI现状取证报告 P0-3`）：`colors_and_type.css`（旧色板 136 行）与 `tokens.css`（新 token）同时被加载；`context.html` 只加载 2 个，`legal.html` 加载 0 个。
- **图标语言三套混用**（`UI现状取证报告 P0-6`）：字符占位（`+ ◇ ○`）、emoji、线性图标，且 dashboard 出现「字符占位当图标」。
- **品牌名两版**（`UI现状取证报告 P0-4`）：dashboard 侧栏 `Proxy Manager` vs floor/context `Multi-Proxy`。

**本文职责**：把"什么算达标"钉死，使后续实施与真实浏览器验收有唯一裁判。所有规格均可在 `tests/design-system.test.js` 与端到端截图复验。

## 1. 设计原则（每条配本项目反例）

1. **单一事实来源**：页面/组件只允许引用 `tokens.css` 变量，禁止散落 hex。反例：`colors_and_type.css` 仍带一套旧色板，与 token 并存引发 `context.html` 缺色（`UI现状取证报告 P0-3`）。
2. **主题必须有线**：暗色不是"画好了没人开"，必须由 `<html data-theme>` + `prefers-color-scheme` 驱动。反例：`tokens.css:93` 暗色块整段死代码（`UI现状取证报告 P0-1`）。
3. **图标是组件不是字符**：禁用 `+ ◇ ○`、emoji 当图标。反例：`dashboard.html` 代理列表前用字符占位（`UI现状取证报告 P0-6`）。
4. **布局跟栅格走**：卡片宽度由栅格决定，禁止手感式宽度。反例：floor 卡片仅 ~200px、dashboard 下排占 2/3（`UI现状取证报告 P0-5`）。
5. **每个页面都进导航**：无导航页 = 死胡同。反例：`settings` / `legal` 导航项 0，进去出不来（`UI现状取证报告 P0-2`）。
6. **文案承诺必须可兑现**：写了"跟随本机外观"就必须真的跟随。反例：`settings.html:34` 文案 vs 全库零 `prefers-color-scheme`（`UI现状取证报告 P0-1`）。

## 2. 色彩系统（已实测对比度）

### 2.1 验收口径
- 正文 / 次文本：**≥ 4.5:1**（WCAG AA 正常文本）
- 大字（≥18.66px 粗体 / ≥24px）/ UI 组件、占位、时间戳：**≥ 3:1**（WCAG AA 大文本 / UI 组件）
- 文案色一律用语义变量；`--faint` 只允许用于占位/禁用/时间戳，**不得用于正文**。

## 4. 间距与栅格（解决 dashboard/floor 错位）

- 4px 基准（`--sp-1..--sp-12`，`tokens.css:71-72`）。
- **统一外壳**：左侧栏固定 `--sidebar-w:240px`，内容区 `--main-pad:32px` 内边距。
- **主内容栅格**：`--content-max:1200px` 居中；卡片网格用 `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`，**禁止手写 200px 这类魔数**。
  - floor 卡片 ~200px 的 bug（`UI现状取证报告 P0-5`）根因：未用统一栅格，被父容器压缩。统一后最小 280px。
  - dashboard 下排 2/3 宽 bug：同页混用两套布局（上排 4 卡铺满、下排另起 grid）。统一为单一 12 列网格分区。
- 圆角：`--r-sm:6 / --r-md:8 / --r-lg:12 / --r-xl:16 / --r-pill:999`。
- 阴影：`--shadow-sm/md/lg`（柔和，见 `tokens.css:80-82`）。

## 5. 组件规格（视觉 + 交互态 + 焦点环）

> 全部组件在 `components.css` 中应有对应实现；本文规定"必须有哪些态"，由 `05-架构与开发设计方案.md` 落地。

| 组件 | 必备态 | 焦点环规格 |
|---|---|---|
| 按钮 `.btn` | default / hover / active / disabled / focus-visible | `outline:2px solid var(--accent); outline-offset:2px` |
| 卡片 `.card` | default / hover（可点击时） | 同可聚焦元素 |
| 标签 `.tag` / `.badge` | 4 语义色（ok/warn/danger/info）+ 品牌色 | 非交互，无焦点 |
| 表格 | 表头 sticky、行 hover、斑马可选 | 单元格内可聚焦元素走焦点环 |
| 表单输入 | default / focus / invalid / disabled | `border-color:var(--accent)` + 同焦点环 |
| Toast `.toast` | info / success / error，3.2s 自动消（参照 `settings.html:120`） | 不需焦点，但有 `role="status"` |
| 模态 | 遮罩 `--z-modal`、Esc 关、焦点陷阱 | 首元素自动聚焦 |
| 空状态 | 图标 + 文案 + 可能操作按钮（禁止留白页） | 操作按钮可聚焦 |
| 加载骨架 | 占位 shimmer（`--dur` 动画，尊重 `prefers-reduced-motion`） | 无 |
| 导航项 `.nav-item` | default / active / hover / focus；active 用左侧 accent 条区分 | 同焦点环 |

**焦点可见**：任何可聚焦元素在 `:focus-visible` 必须显示焦点环（禁止 `outline:none` 后不补）。键盘 Tab 顺序与视觉顺序一致。

## 7. 暗色主题接线规范（MVP，必须落地）

### 7.1 三态模型
- `data-theme` 取值 `light | dark | auto`，挂在 **`<html>`**（不是 `<body>`，否则不匹配 token 选择器，见 `settings.html:13` 的 bug）。
- **`auto`** = 跟随 OS：`@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { /* 复用 dark 变量 */ } }`。
- 持久化：localStorage `theme`（参照 `settings.html:141` 已有键名），首屏在 `<head>` 内联脚本（FOUC 防控）根据存储/系统设置 `<html data-theme>`。

### 7.2 必须改动（实施清单，归 `05` 文档）
1. 删除 `colors_and_type.css` 旧色板引用，全站只引 `tokens.css` + `components.css`（解决 P0-3）。
2. `legal.html` 补 CSS 引用（当前 0 个，裸 HTML）。
3. `context.html` 补齐缺失的 2 个 CSS。
4. 在 `nav.js`（或共享 `shell.js`）统一注入主题 init 脚本 + 切换器。
5. `settings.html:13` 删 `body.theme-dark`；`:135-142` toggle 改为设 `<html data-theme>`，三态。
6. 加 `<meta name="color-scheme" content="light dark">`，使原生滚动条/表单控件随主题渲染。

### 7.3 验收（真实浏览器）
- 切 `prefers-color-scheme: dark` + `data-theme=auto` → 11/11 页 `themeLinked=true`、背景/文字 computed style 与明色**不同**。
- 手动 `data-theme=dark` 持久化刷新后仍 dark。

## 8. 无障碍（a11y）

- **对比度**：见第 2 节，全部达标。
- **焦点可见**：第 5 节焦点环；禁止 `outline:none` 不补。
- **键盘可达**：所有交互元素 Tab 可达、Enter/Space 激活；导航、tab、模态、下拉均键盘可用。
- **语义**：图标 `aria-hidden` + 文本/`aria-label`；状态用 `role="status"`(toast)、`aria-live`(动态区)；导航用 `<nav aria-label>`。
- **`prefers-reduced-motion`**：动画时长归零或降级（骨架 shimmer、tab 切换）。
- **文案可自修**：错误态给出"为什么 + 怎么办"（参照 `settings.html:146` 占位提示的诚实写法，推广到所有错误）。
