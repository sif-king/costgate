## 使用说明（先读）

1. **「当前状态」三档定义**（判定只依据取证报告 + audit.json + 22 张截图，禁止写 unknown）：
   - `broken`：功能在真实浏览器下不可用、不可达、或数据明显错误；
   - `partial`：能出结果但有取证到的缺陷（口径不一致 / 布局破损 / 文案与实现矛盾等）；
   - `ok`：取证范围内无缺陷证据（注意：取证报告 :138 已声明未逐按钮点击，`ok` 仅指静态渲染与数据正确，交互仍须 E2E 证明）。
2. **验收方式只有两类**：
   - `E2E`（真实浏览器）：凡涉及渲染、布局、主题、导航、交互、多页联动的功能点，一律 E2E。理由：jest 字符串断言已被证明测不出图标压字/栅格错位/主题不联动（取证报告 :16-17），这是本轮的方法论红线。
   - `单测`（jest 可覆盖）：仅限纯逻辑（数据归一、状态机、无渲染的 API 封装）。UI 功能点**不允许**用单测代替验收。
3. 每条正例的断言都是**可机器判定**的（DOM 计数 / computed style / URL / localStorage / 网络状态码）。E2E 跑在隔离实例 `PORT=18801`（取证报告 :29），禁止触生产 18792。
4. 状态栏证据格式：`audit.json:行号` / 截图文件名 / `file:line`。
