## 1. 用户旅程地图

```
[首启] → [同意门 consent.html] → [登录 login.html]
   → [概览 dashboard] ── 看 9 代理状态 / 用量 / 成本
        ├─ 代理配置：起停某代理、看冲突三态(occupied/free/unknown)
        ├─ 盘面 Floor：按 Provider 维度的聚合视图
        ├─ 任务 / 知识 / 技能 / 上下文：运维子区（有则看、无则诚实空态）
        ├─ 日志 Logs：运行/错误日志，可按标签筛选
        ├─ 设置 Settings：外观(主题三态) / 关于 / 更新备份 / 法务入口
        └─ 法务 Legal：用户协议 / 隐私政策（常驻可点）
   → [排障]：某代理红 → 看 logs + 冲突检测 → 处理
   → [退出]：desktop 壳 Cmd+Q / 网页关闭
```

关键体验门槛（OOBE 评审结论，见 `OOBE-E2E-总报告与优先级-2026-10-22.md`）：
- 30 秒内能说出"这东西是干嘛的"（首屏价值主张必须明确）。
- 首次起停代理的引导（"点击启动 → 看状态变绿"），避免"按钮点了没反应"的困惑。

## 2. 信息架构（重构后）

### 2.1 页面树（13→12，index 并入 dashboard）

```
/            → dashboard（概览，= 旧 index + dashboard 合并）
/floor       → 盘面（Provider 聚合）
/proxy-config→ 代理配置（9 代理 + 冲突三态）
/tasks       → 任务管理
/knowledge   → 知识库
/skills      → 技能
/context     → 上下文组成
/sessions    → 会话（如确无数据→诚实空态，不删页）
/logs        → 日志
/settings    → 设置（外观/关于/更新备份/法务）
/legal       → 法务（也可从 settings 二级入口 + 底部常驻链接到达）
/login       → 登录（非导航内）
/consent     → 首启同意门（非导航内）
```

### 2.2 统一导航模型（解决 P0-2「进去出不来」）

- **单一 `nav.js`（或 `shell.js`）** 由所有页面 `<script src>` 引入（现状仅 dashboard 1/13，见 `UI现状取证报告 P0-2`）。
- 侧栏项固定 **10 项**：概览 / 盘面 / 代理配置 / 任务 / 知识库 / 技能 / 上下文 / 会话 / 日志 / 设置。
- 底部常驻：**法务** 链接（保证 legal 可达，即使不在主侧栏）。
- 激活态规则：当前路由匹配项高亮（左侧 accent 条，见 `04 §5`）。
- `proxy-config` 现有「← 返回概览」是死胡同写法，改为统一侧栏。
- 品牌名统一为 `Multi-Proxy Manager`（侧栏顶部）。

### 2.3 进/出口契约
- 每个页面：**必有侧栏（入口全集）+ 主内容 + 底部法务链接**，保证任意页都能走到任意其他页。
- 错误/空态页也要有侧栏（当前 legal/settings 无导航 = 死胡同，必须修）。

## 4. 交互规格

### 4.1 导航切换
- 侧栏点击 → SPA 式路由或整页跳转均可，但**必须保留侧栏与底部法务链接**（杜绝死胡同）。
- 焦点：侧栏项 `:focus-visible` 显示焦点环；当前路由项 `aria-current="page"`。

### 4.2 主题切换（三态）
- 顶栏主题按钮 + 设置页三态选择器，二者同步（同一 localStorage 键 `theme`）。
- `auto` 时实时响应系统切换（`prefers-color-scheme` 媒体查询，不需刷新）。
- 首屏 `<head>` 内联脚本防 FOUC。

### 4.3 9 代理卡片 + 冲突三态
- 每张卡：Provider 品牌色徽标（SVG）、名称、运行状态（运行/停止）、冲突态（occupied/free/unknown，见 `04 §6.2 #12`）。
- 启动/停止按钮：点击 → 调 API → 乐观更新 + 真实状态回写（禁止"点了没反应"；当前 `01` 指出 dashboard 有 5 个无落地 BUTTON，实施前需逐一点击取证再裁决，见 `01 §7(F)`）。
- unknown 态：明确提示"未能探测，可能未安装/未启动"，不假装成空闲。

### 4.4 错误/空态
- 任何数据请求失败 → 错误卡（图标 + "为什么" + "重试"按钮）。
- 无数据 → 诚实空态（"暂无 X，点这里创建/启动"），**禁止留白页**（P0-9）。

## 5. 原型

- **可交互高保真原型**：`docs/design/prototype/index.html`（单文件、零外链、真实 `data-theme` 三态切换）。
- 原型覆盖：顶栏 + 统一侧栏（10 项 + 底部法务）、Dashboard（9 代理卡 + KPI）、设置（三态主题真生效）、代理配置（9 代理 + 冲突三态）、法务。
- 原型中可演示：主题三态切换、导航切换、空态/加载骨架/错误态（用按钮切换状态演示）。
- **原型是唯一视觉对齐基准**，实施时页面必须与之一致（栅格、色板、图标、间距）。
