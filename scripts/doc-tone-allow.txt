# 对外文档语气体检的白名单（scripts/check-doc-tone.js 读它）
#
# 格式：文件<TAB>规则<TAB>理由
#   - 文件：相对仓库根，与脚本 TARGETS 里写法一致
#   - 规则：D1 / D2 / D3 / D4 / D5（见 docs/12-docs/DOCS-METHODOLOGY.md §7.1）
#   - 理由：必须写清「为什么这条判据在这份文件上不适用」，会原样打进输出
#
# 三条规矩：
#   1. 只允许「判据不适用」，不允许「先放过」。写不出理由就是文档该改。
#   2. 逐条引用坏句子（对照表、反例）不要用这个文件，用正文里的
#      <!-- doc-tone:off --> … <!-- doc-tone:on --> 包起来：范围是局部的，每次运行还会报数。
#   3. 加了白名单必须在提交信息里说明是哪一个 D 项、为什么。
#
# 当前为空（2026-11-13 首次全量通过）。示例（保持注释状态，别直接启用）：
# README.md	D1	正文需要引用一段上游原文，原文本身带破折号
