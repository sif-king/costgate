Codex、Claude Code、Cursor 一起开着的时候，
谁花了多少，你得有一本自己的账。

一条命令装好，看到第一笔真实账单，不用填 API key。跑完 quickstart，屏幕上会打印刚记下的那一笔：进了多少 token、出了多少、多少钱、用了多久。账本就在你硬盘上，是一个文本文件，想翻随时用只读命令翻，哪个开关真跑过几次也查得到。

git clone https://github.com/sif-king/costgate && cd costgate
bash scripts/quickstart.sh
读 README 数据去哪了 已知限制

第一次要装依赖，脚本末尾会打印这次实际花了多久。快慢看你的网络和缓存。

装完之后，这几件事你自己就能查

屏幕上会多出一行账

脚本装好依赖、找到不用填 key 就能用的上游、起两个进程、发一个真请求，最后把刚落地的那一笔打印出来：入多少、出多少、多少钱、用了多久。

账本就在你硬盘上

账本写在你硬盘上，是一个纯文本文件。服务停了它也还在，另有一条只读命令能翻出每一笔，也能看出哪个开关真跑过、跑过几次。

密钥留在你自己手里

key 写在你自己的配置文件里，没有遥测，也没有回传。验证脚本全程只读本地文件，不发一个出网请求。

装完默认是什么样

能力默认说明
请求账本与脱敏开不用先设置，第一次请求就记上了
路由、熔断、重试、任务编排关每项单独一个开关，开了才改行为。没开的时候页面会直说没开，不会只留一片空白让人以为出了故障
知识库、技能扫描等进阶能力关默认什么都不动，要用的时候去设置里打开

每个开关叫什么、怎么验，仓库里的 COMPATIBILITY.md 和 README 都写了。面板最上面那条也会显示此刻是开是关。

用起来之后

把常用的工具接进来

Claude Code、Codex CLI、Cursor、opencode、Cline、Aider 都能接。装的时候先看这些工具有没有抢同一个配置，撞了就报出来，不改你已经写好的文件。

它现在还做不到的事

现在它只管一台机器、一个人、一个成本池。多租户、SSO、企业分账都没有做，也没有别的产品接着提供。还没发正式版本号，接口会变；要放到生产上，先把已知限制读完。
