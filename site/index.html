首次会安装依赖，脚本末尾会打印本次真实耗时，不承诺固定秒数。

三件马上能自己验的事

看到第一笔真实账单

脚本装好依赖、探到零 key 上游、起两个进程、发一个真请求，末尾把刚落地的那一笔打印出来（入 / 出 / 费用 / 耗时）。

每笔账可以自己查

账本是本机磁盘上的文本，不藏在服务里。只读命令能把它读出来，也能看出哪项能力真的跑过、跑过几次。

数据不出本机

密钥留在你自己的配置文件里，没有遥测、没有回传。验证脚本全程只读本地文件，不发一个出网请求。

默认开什么、默认关什么

能力默认说明
请求账本与脱敏开装上就有账，第一次用就能看见
路由、熔断、重试、任务编排关每项是独立开关，开了才改行为；没开时页面会明说没开，不会伪装成「没数据」
知识库、技能扫描等进阶能力关默认零副作用，需要时在设置里开启

开关的完整清单与验收方式见仓库里的 COMPATIBILITY.md 与 README，页面上方的能力条也会显示当前状态。

想再往前一步

接上你自己的工具

支持 Claude Code、Codex CLI、Cursor、opencode、Cline、Aider 等。工具之间是否抢了同一个配置，装的时候会先查再报冲突，不覆写你的配置。

看清楚边界

单机单用户，不提供多租户、SSO、企业分账。当前没发正式版本号，接口会变，上生产前请先读已知限制。
